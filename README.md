## Projects
* 🤖 **[face-recognition-attendance-system](https://github.com/prathamkun/face-recognition-attendance-system)** - AI-powered attendance system using OpenCV, face_recognition, Flask, and SQLite to automate attendance tracking with real-time face verification and duplicate prevention.
* 😊 **[emotion-detection-model](https://github.com/prathamkun/Emotion-Detection-Model)** - Deep learning application built with TensorFlow, Keras, and OpenCV that detects human emotions in real time from webcam input using a CNN trained on the FER-2013 dataset.
* 🏠 **[ai-house-price-predictor](https://github.com/prathamkun/ai-house-price-predictor)** - Full-stack machine learning application that predicts house prices using regression models, Flask APIs, and a modern web interface deployed on Render.
* 🎓 **[placement-prediction-app](https://github.com/prathamkun/placement-prediction-app)** - Machine learning web app built with Streamlit and Scikit-learn that predicts student placement outcomes based on academic performance metrics.
* 🎬 **[prathamflix](https://github.com/prathamkun/Prathamflix)** - Netflix-inspired streaming platform built with React, Firebase, and TMDB APIs featuring authentication, protected routes, custom content management, and responsive UI.
* 🎥 **[streamify](https://github.com/prathamkun/streamify)** - Modern video streaming platform featuring a glassmorphism-based UI and responsive user experience inspired by contemporary media applications.
* 🍔 **[food-order-system](https://github.com/prathamkun/FoodOrderSystem)** - Database-driven food ordering application built with MySQL, demonstrating backend development, relational database design, and order management workflows.
* 🧶 **[craftify](https://github.com/prathamkun/craftify.com)** - Marketplace platform designed to help artists and homemakers showcase and sell handmade products through a simple and accessible online storefront.
* 🩺 **[pocket-medKit](https://github.com/prathamkun/pocket-medkit)** - Startup-focused healthcare website designed to present and promote a portable emergency medical kit through a clean and informative user experience.
* 🔳 **[upi-qr](https://github.com/prathamkun/qrcode-generator-python)** - Python-based utility that generates UPI payment QR codes through an easy-to-use web interface powered by Streamlit.
